# Vodafone-Sales-Forecasting-Ensemble-Machine-Learning-Model
Developed as part of a Vodafone PT job assignment, this project features an AI-generated 11-year dataset and a robust forecasting system combining machine learning and time series modeling to predict daily and monthly sales with realistic seasonality and high accuracy.

How use this notebook:

- Download these files to a folder on your computer:
    - vendas_loja_vodafone_braga.csv                                         (this file contains the AI generated dataset)
    - feriados_braga_2026_2027.csv                                           (this file contains the holidays affecting the subject store)
    - Vodafone Sales Forecasting – Ensemble Machine Learning Model.ipynb     (this file contains the Jupyter Notebook)

- Open file Vodafone Sales Forecasting – Ensemble Machine Learning Model.ipynb on Jupyter Notebook;

- On Jupyter "Edit" menu, select "Find...", copy the phrase "REPLACE WITH PATH TO THE FOLDER WHERE THE PROJECT IS LOCATED ON YOUR COMPUTER AND KEEP THIS FILE NAME>>>>" and paste it to the Find box. Copy the folder path where you have stored the project files you previously downloaded, paste the path on the Find box second line and press "Replace All". IMPORTANT: copy the folder path and erase the "" that come before and after the folder path, so that the path has no double "".

- On Jupyter Notebook "Run" menu, press "Run All Cells" and observe the code outputs.
